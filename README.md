# Free Roblox Vault Door Script (Luau)

A lightweight, open-source vault door interaction script for Roblox Studio using TweenService.

## How to Install
1. Copy the code inside `VaultDoorScript.luau`.
2. Create a Script in `ServerScriptService` in Roblox Studio and paste the code.
3. Ensure you have two parts in Workspace named `VaultDoor` and `VaultPad`.
